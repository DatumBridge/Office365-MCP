# ADR-0002

## Status

Accepted. 2026-10-30.

## Context

`read_file` returned Excel workbooks as base64. Agents cannot use cell values from that blob. A separate Excel tool would duplicate drive selection, auth, and item lookup that `read_file` already performs.

## Decision

Extend `read_file` with `excel_format` (`json` or `xml`), optional `sheet_name`, and optional `header_row`. Parsing is in memory with `openpyxl` (`read_only`, `data_only=false`, `keep_links=false`). Formulas are returned as text. Macros are not executed. Legacy `.xls` is rejected. Package size and cell counts are capped, and a partial read sets `truncated=true`.

When a transform succeeds, the response carries `content_json` or `content_xml` plus `content_text`, and omits `content_base64`. Calls that omit `excel_format` are unchanged.

## Alternatives Considered

- Graph workbook range API (`/workbook/worksheets`). Rejected: needs extra Excel permissions and a different item model, and still fails for files that are not open in Excel Online.
- Always parse every Excel download. Rejected: existing callers expect base64, and parsing has a CPU and memory cost.
- Evaluate formulas. Rejected: that executes attacker-controlled expressions and needs a calculation engine.
- Support BIFF `.xls`. Rejected: it is not an Open XML package and needs another parser.

## Consequences

- Image rebuild must include `openpyxl`.
- Tool Registry docs for every Office 365 tool, including `read_file`, follow the MCP guide contract. Agents must pass `excel_format` to get cells.
- `download_file` stays a raw download.

## Trade-offs

- One tool instead of a second Excel tool. The `read_file` schema is larger.
- Cached calculated values are not substituted for formulas. Callers see `=B2*2`, not the last Excel result.
- `openpyxl` increases the image. It does not add a network client.

## Risks

- Workbook XML is still parsed by a library after the ZIP caps. Caps bound declared expansion; they are not a sandbox.
- Cell text can contain instructions aimed at a model. Callers must treat it as data.
- Very wide or very long sheets are truncated. The flag is the signal that the sheet is incomplete.

## Rollback

Remove `excel_format` handling and redeploy the previous image. Callers that omit the argument already match the old behavior.
