# ADR-0001

## Status

Accepted. This records the server's existing shape.

## Context

DatumBridge needs OneDrive and SharePoint file tools for agents. Mail is a different Azure app and a different MCP server.

## Decision

`office365-mcp` is a FastMCP server that calls Microsoft Graph with a delegated OAuth token. File tools operate on `/me/drive` or a SharePoint site drive. PDF and Office files are in scope. Outlook mail is out of scope.

## Alternatives Considered

- Microsoft Graph application permissions. Rejected: file access should stay inside the signed-in user's rights.
- Putting mail and files in one Azure app. Rejected: consent and blast radius stay separate (`outlook-mcp`).

## Consequences

- Every file tool requires `credentials_path` or `credentials_json`.
- Writes that delete or upload require `confirm=true`.

## Trade-offs

- Delegated tokens expire and must refresh. The server never returns the token in a tool result.

## Risks

- A stolen delegated token can read the user's files. Tokens stay in the credential vault and are not logged.
